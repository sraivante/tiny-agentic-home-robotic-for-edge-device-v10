Union Command v10 · Test guide

Say it in English or Hinglish. Get a function call your agent can run.

Union Command v10 is a small offline model that turns one spoken or typed command into a structured action with typed arguments, for laptops and Raspberry Pi. This page shows what it does, how to download and test it, and how it scored.

The executor is sample testing only, not fully developed. The model parses; the included executor exists so you can watch a parsed command become a real action. It refuses every critical action by default. Use a test machine and read each plan before you run it.

How it fits in an agent

Voice or text→Speech-to-text (optional)→Union Command v10→Validator + risk gate→Executor (tool call)

It covers 371 actions across 17 categories. Every prediction includes a confidence score, the top-3 alternatives and schema validation errors, so an agent can execute, ask the user (clarify) or hand the text to a larger LLM (unknown or low confidence).

Download and test

1 · Get the code and model

git clone https://github.com/sraivante/union-command-minilm-v10.git
cd union-command-minilm-v10
python download_model.py

The downloader fetches the 96.2 MB model from Hugging Face and verifies its SHA-256.

2 · Install (Python 3.11–3.13, CPU)

python -m venv .venv
# Windows: .venv\Scripts\activate
# Pi/Linux: . .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

3 · Parse commands (no execution)

python quickstart.py
python quickstart.py "wifi band karo"
python quickstart.py --json "5 minute ka timer lagao"

4 · Reproduce the tests

python scripts/evaluate.py --data examples/sample_commands.jsonl
python scripts/benchmark.py --threads 1,2,4

5 · Sample executor lab (optional)

run.bat          # Windows
bash run.sh      # Linux / Raspberry Pi
# opens http://127.0.0.1:8770

Local only, token-protected, file actions confined to runtime/files/. Critical actions need --allow-risk critical.

Python API

from tinyagent.runtime import Predictor
m = Predictor("models/a100_minilm_v10_quoted/best.pt", threads=2)
print(m.predict("volume 40 kar do"))

Limitations

  • Synthetic training data with no real speech-to-text output; test with your own ASR transcripts.
  • Small Devanagari coverage; English and Roman-script Hinglish dominate.
  • One command per utterance; it parses, it does not plan.
  • Weakest spots: near-duplicate GPIO/I2C actions, a few near-synonyms and some free-text argument boundaries.
  • The model never refuses; always keep a validator and risk gate in front of an executor.
